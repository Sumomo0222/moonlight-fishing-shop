# 🌙 月光钓鱼小铺 · Moonlight Fishing Shop

一个打开链接就能玩的治愈系互动小网页：夜色湖面、木栈桥、一盏灯笼挂在屋檐下的钓鱼小铺。点「抛竿」，看浮漂落进月光里；浮漂开始晃动时按下「收线」，随机钓起一件奇妙的小东西，弹出一张可以分享的收获卡片。

所有画面元素（小铺、湖面、月亮、鱼竿、浮漂、收获物）均使用 HTML / CSS / SVG 手绘，**无任何外部图片素材、无框架、无构建步骤**。

## 它是什么

- 一个单页轻量互动小 游戏 / 氛围玩具，玩法约 10 秒一轮：抛竿 → 等待 → 浮漂晃动 → 收线 → 收获卡片。
- 8 种随机收获：银色小鱼、漂流瓶、旧电台、星星鱼、月亮贝壳、发光水母、云朵罐头、许愿石，分「寻常 / 稀有 / 传说」三种稀有度。
- 场景分前景（木栈桥、小铺、灯笼、猫老板、鱼竿）、中景（湖面、浮漂、波纹、小船）、背景（月亮、星空、远山小塔、流星）三层，带水雾与漂浮光点等氛围细节。

## 本地打开

方式一（最简单）：直接双击打开 `dist/index.html` 即可，无需服务器。

方式二（可选，本地静态服务）：

```bash
cd dist
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 交互说明

1. **抛竿**：点击底部主按钮，鱼竿把浮漂抛向湖面（抛物线动画 + 落水水花）。
2. **等待**：浮漂随波轻晃，周围偶尔泛起涟漪；按钮显示「等鱼上钩…」（此时不可收线）。
3. **咬钩**：1–3 秒后浮漂开始抖动、按钮变为「收线！」并呼吸发光；犹豫太久小鱼会溜走，需要再等下一次咬钩。
4. **收线**：鱼线回拉、收获物跃出水面、星光四溅。
5. **收获卡片**：居中弹窗展示收获插画、名称、描述、分享短句；点「再钓一次」直接自动抛竿，或点「复制收获文案」把分享句复制到剪贴板。
6. 鱼篓计数会保存在浏览器 `localStorage`，刷新不丢。按 `Esc` 或点击遮罩可关闭卡片。

## 部署方式

`dist/` 是纯静态目录（`index.html` + `style.css` + `script.js`，全部为相对路径引用），可部署到任意静态托管 / CDN：

- **GitHub Pages**：把仓库推到 GitHub，在仓库 Settings → Pages 里选择分支 + `/dist` 目录即可。
- **jsDelivr CDN**：仓库公开后，直接用 `https://cdn.jsdelivr.net/gh/<用户名>/<仓库名>@<分支>/dist/index.html` 访问。
- **其他**：Netlify Drop、Cloudflare Pages、Vercel、对象存储 + CDN 等均可，把 `dist/` 作为站点根目录上传。

## 可以继续优化的方向

- **图鉴系统**：记录每种收获的收集进度，集齐全部 8 种解锁彩蛋结局。
- **音效**：用 Web Audio API 合成水花、收线、铃铛声（依然零素材）。
- **昼夜与天气**：根据真实时间切换黄昏 / 深夜 / 黎明色调，偶发下雨或起雾。
- **钓到大鱼**：收线时加入「拉扯对抗」小游戏（按住-松开节奏条）。
- **分享图片**：把收获卡片用 Canvas 生成一张可保存/分享的图。
- **多语言**：抽取文案表，支持英文切换。
- **PWA**：加 manifest 与 Service Worker，支持离线与添加到主屏。

## 技术说明

- 桌面端与手机端均已适配：场景元素尺寸随视口缩放，页面无横向滚动，弹窗在小屏完整可见。
- 浮漂晃动前主按钮处于禁用状态，符合「晃动后才允许收线」的规则。
- 遵循 `prefers-reduced-motion`，为减少动态偏好的用户降低环境动画。
